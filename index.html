01 • Project Foundation

Introduction, Problem Statement & Objective

Connecting Artificial Intelligence and computer vision principles with semiconductor manufacturing and electronics quality assurance.

IN

Project Introduction

Semiconductor chips power computers, smartphones, vehicles, communication systems, and modern electronic devices. During wafer and chip fabrication, microscopic surface or pattern defects can degrade device reliability. AI-assisted image classification supports faster, consistent visual inspection.

PS

Problem Statement

Manual visual inspection of semiconductor wafers and chip surfaces can be time-consuming, repetitive, and difficult to scale consistently across high-volume manufacturing lines, creating a need for automated visual screening support.

OB

Project Objective

To explain and design an AI-based image inspection system that analyses semiconductor wafer or chip-surface images and classifies visible defects into structured categories to assist quality control in electronics manufacturing.

Planned Evaluation Framework (Future Testing)

Before deploying an AI inspection model in a real manufacturing setting, performance must be benchmarked on unseen test images using standard classification metrics:

Accuracy Overall proportion of correctly classified wafer images.
Precision Reliability of defect alerts (minimizing false alarms).
Recall Sensitivity to catching true surface defects.
Confusion Matrix Class-by-class breakdown across all 5 categories.
