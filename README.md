During silicon wafer and chip manufacturing, microscopic surface or lithography pattern defects can degrade device performance and yield. Because manual visual inspection can be time-consuming and difficult to scale consistently, this project explores how Artificial Intelligence (AI), image preprocessing, and Convolutional Neural Networks (CNNs) can support faster, more consistent visual quality inspection.Project Scope Notice:This repository and digital portfolio document a conceptual AI project architecture, labelled dataset organization plan, and visual inspection workflow. It does not claim measured industrial accuracy or a completed semiconductor fabrication deployment.Portfolio Highlights (index.html)The portfolio is built as a self-contained, responsive single-file web application (index.html) featuring:Interactive AI Chip Inspection Schematic: Recreates the semiconductor wafer quality-check diagram with clickable defect nodes (Scratch, Crack, Particle, and Pattern).5-Class Interactive Defect Explorer: Visualizes simulated optical micrographs, AI bounding-box overlays, preprocessing notes, and expected conceptual classifier actions across all five wafer surface categories:Normal Surface (Defect-free reference)Scratch (Linear mechanical surface abrasion)Particle / Contamination (Foreign dust or chemical residue)Crack (Structural crystalline micro-fracture)Pattern Irregularity (Lithography or etching distortion)End-to-End AI / CNN Inspection Workflow: Interactive 5-stage pipeline walkthrough:
